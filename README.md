# Wedded · Sophie & Matteo Wedding Invitation Website

A faithful, fully responsive, and standalone recreation of the **Wedded** Framer wedding invitation template.

## ✨ Features Included
- **Hero & Live Countdown:** Real-time countdown ticker to Saturday, 15.08.2026 (Florence, Italy).
- **Our Story (3D Flip Polaroids):** Interactive polaroids that flip 180° upon click to reveal personal memories & dates.
- **Location & Venue Slideshow:** Villa Cora photo gallery with previous/next controls, dot indicators, and auto-play.
- **Travel & Accommodations:** Travel guide (Flight, Shuttle, Car) and hotel cards with discount codes.
- **Schedule of The Day:** Interactive timeline from 14:00 ceremony to late-night dancing.
- **Attire & Dress Code:** Palette color swatches with guidance for ladies and gentlemen.
- **Wedding Registry / Honeymoon Fund:** Bank transfer details with 1-click IBAN copy.
- **Interactive RSVP Form:** Full name, attendance selection, dietary notes, +1 guest with instant confirmation & local storage persistence.
- **FAQ Accordion:** Expandable answers for guests.
- **Romantic Ambient Music:** Built-in floating audio widget playing romantic melodic chimes via Web Audio API.

## 🚀 How to Run

### Option 1: Direct in Browser (No installation needed)
Simply double-click `index.html` to open it in Chrome, Edge, or Safari. All 29 images and assets are stored locally in `assets/images/`.

### Option 2: Run with Vite Dev Server
```bash
npm install
npm run dev
```

## 📁 File Structure
```

├── package.json      # Vite dev server configuration
```
